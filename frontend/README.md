# CrimeMind Frontend

React + Vite investigator dashboard.

## Run
```powershell
cd CrimeMind-Frontend
npm install
npm run dev
```

Default backend: `http://127.0.0.1:8000/api`

Set `VITE_API_BASE_URL` in `.env` if needed.

The UI is case-independent and uses evidence-first labels. It does not determine guilt.
